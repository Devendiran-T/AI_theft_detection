# AI Theft Detection

A Python‑based home security system that uses YOLOv8 for real‑time person detection and sends alerts (including two photos) to a Telegram chat.

- **Live detection** using your webcam
- **Night‑mode** brightness boost
- **Configurable** confidence, zone, and cooldown intervals
- **Telegram notifications** with two photos per alert
- **No local snapshot storage** (photos are only sent via Telegram)

The code is hosted at: https://github.com/Devendiran-T/AI_theft_detection
